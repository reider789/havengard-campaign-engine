# Общие анимации боя — 30.6.0

Обе настольные точки входа Хейвенгарда собраны тем же модулем `core/visual_fx.js`, что и Рин. Версия и неизменяемый коммит закреплены в `prototypes/shared-combat/engine-lock.json`; самостоятельной копии анимаций для партии нет.

Добавлены движение по фактическому маршруту, выпады/безоружные удары, стрелы и метательное оружие, грозовые разряды, попадания/промахи/криты, магические области разных стихий, паутина/туман, Рука Бигби, телепортация с пассажиром, лечение, защита и прерывание заклинаний. Постоянные состояния и концентрация отмечены без мерцания. Это эффекты жетонов/поля, не анимированные модели персонажей.

«Бои и настройки → Анимации боя»: выключены / обычные / насыщенные, скорость ×1 / ×1,5 / ×2. Уменьшение движения в системе отключает анимации. При открытии сохранения и переключении боя история не проигрывается; при реакции движущийся дубль убирается. Эффекты не задерживают команды и не перехватывают клик. Лимит — 24/40 временных элементов, без постоянного JS-цикла и накопления очереди.

Подключение основано на типах событий и ID, а не именах или тексте журнала. Отдельное событие `spellResolved` не появляется у отменённого заклинания, поэтому Контрзаклинание не сопровождается ложным взрывом. Данные канона, текущие ресурсы героев и правила расходования не изменены.

Проверки:

```sh
python tools/check_shared_combat.py --engine-root ../rin_dnd --require-ready
python tools/test_shared_handoff.py ../rin_dnd
python tools/test_shared_browser.py
python ../rin_dnd/tools/test_browser_visuals.py --html prototypes/chat-combat/desktop-battle.html
```

Браузер партии отдельно проверяет настоящий Огненный шар Дафны и появление области, сохранение/загрузку без повторных эффектов, реакцию Контрзаклинания и три настольных размера. Общий браузерный набор исполняет также все группы анимаций, невидимость, длинный журнал, лимиты/очистку, системное уменьшение движения и изменённую геометрию. Прежние полные бои, продолжение эффектов и переход в следующий бой проверяются на копиях; живой канон от тестов не меняется.
