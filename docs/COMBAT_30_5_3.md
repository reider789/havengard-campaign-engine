# Обновление общего боевого движка 30.5.3

Исправлены C01–C10 повторного аудита. Общий код закреплён неизменяемым commit в `prototypes/shared-combat/engine-lock.json`; оба настольных HTML пересобраны из этого кода и текущего канона.

В адаптере исправлены перенос опутывания паутиной и восстановление поля после боя неполной партии. Сравниваются поля действующих зон и объектов; исторические пустые сцены отсутствовавших героев не создают конфликт. При возвращении остальных героев выбираются свободные клетки. Разные поля с действующими пространственными эффектами по-прежнему отклоняются.

Окончание Помощи снимает прибавку максимальных и текущих ПЗ. Падение до 0 прекращает концентрацию, связанные условия и захваты; повторная синхронизация ничего не списывает. Входные данные транзакции копируются, чтобы производные изменения не меняли исходный отчёт и его контрольную сумму.

Общий движок исправляет архив сохранений, реакции, движение, сопротивления, старые незавершённые удары, иммунитеты, страх, окаменение и рост. Старые частично разрешённые удары завершаются без повтора уже нанесённого урона. Полное описание — `docs/CORRECTNESS_30_5_3.md` в закреплённом SDK.

Проверки:

```sh
python tools/run_tests.py
python tools/check_shared_combat.py --engine-root ../rin_dnd --require-ready
python tools/test_shared_handoff.py ../rin_dnd
python tools/test_shared_browser.py
```

Сквозной набор действительно создаёт паутину и Руку Бигби, принимает отчёт в копию канона, собирает новый пакет и инициализирует следующий бой. Дополнительно проверены повторный приём отчёта и отклонение реального конфликта действующих полей. Ревизия канона 31 и её контрольная сумма не меняются от этих проверок.
