# Хейвенгард — тактический бой в чате (v26)

## Фэнтезийное оформление

Оригинальный стиль **Heroes-inspired**: бронзово-древесные панели, выделенные герои и враги, выразительные кнопки и читаемое поле 11×8. Файл fantasy_ui.css встроен в HTML, шрифты и оформление не требуют интернета.

## Анимации

Файл core/visual_fx.js не изменяет механику. Он читает события журнала и состояние боя: попадание, промах, урон, заклинания, защитные реакции и состояния (огонь, яд, холод, паутина, благословение, щит, прицел).

Режимы: **Выключены** (без эффектов), **Стандарт** (вспышки, руны, всплывающий урон и кольца состояний), **Красиво** (снаряды и круги по площади). Одновременно не более 16 временных элементов, автоматическая очистка за секунду, без постоянно работающего Canvas/WebGL. По умолчанию «Стандарт», а при системном предпочтении уменьшенного движения — «Выключены». Выбор хранится в браузере и не входит в сессию.

## Сборка и защита игровых данных

engine-v26.html сохраняет игровые правила v25. build_chat_bundle.py включает визуальные слои в один автономный current-chat-battle.html для запуска внутри ChatGPT. Игрок не загружает файлы и не использует отдельный сайт. При наличии сети дополнительные изображения местности автоматически загружаются из фиксированного CDN, при её отсутствии работает CSS-фэнтези.

Формат учебного сохранения — version:12. Визуальные события не изменяют ПЗ, ресурсы, инициативу и канонический файл state/_campaign-state.json. Браузерный тест tests/qa_v26_fantasy_fx.py проверяет режимы, предел эффекта, отсутствие влияния на данные, мобильный интерфейс и reduced motion. Старые боевые тесты и v25 сохранены.
