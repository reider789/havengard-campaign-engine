# Настольный бой Хейвенгарда · общее ядро 30.5.2

Основной запуск — `desktop-battle.html` отдельной файловой ссылкой в ChatGPT. Поле открывается в просторной области рядом с чатом. Та же автономная сборка доступна как `current-chat-battle.html`. Сеть и установка зависимостей для игры не нужны. Разработка ориентирована на настольный браузер.

Полная текущая партия — Яр, Дафна, Лютобор и Рада. Все четыре героя управляются игроком; необязательные реакции требуют решения. Единственная заданная автоматическая реакция — Щит Дафны, когда +5 КД превращает попадание в промах. Карточка, подготовка и снаряжение доступны в интерфейсе. Заклинания выбираются вместе с кругом, целями, защитой Скульптурой и точкой на карте. Режимы Руки Бигби и решения после попадания используют то же ядро.

Состояние ресурсов приходит из канона. Заряды предмета и дневные применения учитываются отдельно; боеприпасы не восстанавливаются отдыхом. Ненадетая броня, настройка и расходуемые компоненты влияют на доступность действий. Справочная книга не расширяет текущую подготовку.

Сборка:

```sh
python tools/build_shared_combat.py --engine-root ../rin_dnd
python tools/check_shared_combat.py --engine-root ../rin_dnd --require-ready
python tools/test_shared_handoff.py ../rin_dnd
python tools/test_shared_browser.py
```

`prototypes/shared-combat/engine-lock.json` закрепляет поставку. `reviewed-profiles.json` и аудит проверяют актуальную карточку, ресурсы и обработчики. Изменение механики блокирует сборку до проверки адаптера. Источники общего ядра здесь не дублируются.

Учебная встреча не является сыгранным событием. Сюжетный сценарий должен явно указать постоянный battle_id, текущую ревизию и хеш канона. `tools/build_shared_story.py` собирает такую сцену. `tools/import_shared_combat_result.py` проверяет завершённый отчёт и готовит транзакцию кампании; повтор одного результата не расходует ресурсы снова. Импорт учебного результата запрещён. Технические проверки выполняются на копиях, не продвигают живую историю.

Сохраняются бой, очередь, реакции, RNG и эффекты. Незавершённое решение блокирует финальный отчёт. Локальное сохранение и сохранение в хосте независимы. Завершённый отчёт скачивается кнопкой «Итоги для мастера». Художественное продолжение следует [NARRATIVE_CONTRACT.md](NARRATIVE_CONTRACT.md): без метагейма и выдуманных решений героев.

«Бои и настройки» показывает заполнение архива и позволяет выгрузить старые бои, удалить выбранную локальную копию и восстановить бой из архива. Удаление старого боя доступно после выгрузки. Для большого текущего журнала есть отдельная явно подписанная команда скачивания, удаления локальной копии и начала новой тренировки. Новое прохождение не перезаписывает прежнее по ID сценария. Рассеивание магии предлагает отдельный выбор объекта или эффекта, включая Руку Бигби.

`engine-v18.html` … `engine-v29.html`, их модули и QA — архив. Активный бой v29 продолжается в v29 и не преобразуется переименованием JSON. Старые встроенные загрузчики и gzip-пакеты не являются текущим способом запуска. Их нельзя использовать для нового боя.
